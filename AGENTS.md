# Repository guidance

## Writing notes

- Organize notes around realistic events or incidents, guiding readers through the problem, investigation, and solution as a story.
- Use example names, commands, and output where helpful. Make clear when a scenario or details are illustrative; do not present invented events as verified history.
- Use tables when they make information easier to understand, such as for command output or comparisons.
- Keep commands, explanations, and relevant cautions practical and easy to find.
- Follow the note organization and maintenance workflow in [CONTRIBUTING.md](CONTRIBUTING.md).

## Publishing changes

- Whenever you add or update notes, commit the changes and push them to `main`.
